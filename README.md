## 方法

三段流水线，由 `MODE` 控制：

1. **去对齐（核心）**：裁掉左上边缘约 9.4% 的像素后缩放回原尺寸，使 8×8 分块网格
   整体错位。对基于固定网格的频域/空间水印（DCT/DWT 扩频、LSB 分块等）而言，
   检测统计量与嵌入网格失配，相关性趋近于 0。
2. **质量预算回拉**：先按最大强度攻击，再用解析解把输出朝输入缩放，直到刚好满足
   质量红线（PSNR ≥ 29 dB，留 1 dB 余量）。把质量约束当成"预算"用满，而不是保守绕开。
3. 可选的前置 JPEG / 模糊（`STRONG` 档），提升对其他类型水印的覆盖。

## 实测（自建 DCT 中频扩频代理检测器，32×32，300 张图）

| 模式 | PSNR | SSIM | 抑制率 | 检测 AUC | 耗时/样本 |
|---|---|---|---|---|---|
| LIGHT（默认） | 35.5 dB | 0.902 | **99.4%** | **0.336** | 0.8 ms |
| STRONG | 36.6 dB | 0.929 | 63.7% | 0.94 | 4 ms |
| A0（平台基线） | 39.2 dB | 0.956 | 27.6% | 0.997 | 3 ms |

`LIGHT` 档检测 AUC 低于 0.5，说明水印不仅被消除，检测分数还出现系统性反转，是攻击效果
最强的一档；其代价是 SSIM 约 0.90，低于主赛道 0.92 的门槛，因此仅在平台（判据为
PSNR ≥ 28 dB）下使用。若需满足主赛道 SSIM/LPIPS 约束，改 `MODE = "STRONG"`。

## 合规

- 不查询防御检测器、不访问防御代码/权重/密钥，不使用网络与外部数据
- 输出保持宽高、三通道、uint8；无 NaN/Inf；不输出空图、纯色图或大面积遮挡
- 不替换图片主体、不添加文字/贴纸/边框；`sample_id` 未被编码进输出图片
